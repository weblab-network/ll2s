LL2S provides a local switch CLI backed by Open vSwitch: VLAN access/trunk ports,
STP/RSTP, LLDP, one management IPv4 endpoint and read-only SNMPv2c.

The prebuilt image is `ghcr.io/weblab-network/ll2s:0.2.0` (`latest` also points to
the released build), for Linux amd64 with the host Open vSwitch module.
See the README for standalone use and the local tag expected by Weblab.

LL2S is intended for labs. Commits interrupt managed ports; `write memory` saves
startup configuration. MSTP, BPDU guard, LACP and SNMPv3 are not implemented.

The attached dependency source bundle contains exact Alpine build recipes,
patches and checksum-verified upstream archives for the released image. It is
separate from the LL2S source archive supplied by GitHub.
